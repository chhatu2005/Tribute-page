# Tribute Page

A responsive single-page tribute website dedicated to Dr. A. P. J. Abdul Kalam.

## About the Project

This project is a static tribute page created using HTML5 and CSS3.
It presents the biography, achievements, and important timeline events
of Dr. A. P. J. Abdul Kalam in a clean and responsive layout.

## Features

- Responsive design for mobile and desktop
- Biography section
- Achievements section
- Life timeline
- Tribute image
- Famous quote
- Semantic HTML structure

## Technologies Used

- HTML5
- CSS3
